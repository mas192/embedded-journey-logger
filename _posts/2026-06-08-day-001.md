## Goal
Understand how a C program is converted into machine code by manually executing the compiler stages.

## Work
- Installed the GCC toolchain.
- Wrote a standard `hello.c` program.
- Executed the preprocessor (`gcc -E`) to generate the `.i` file.
- Executed the compiler (`gcc -S`) to generate the assembly `.s` file.
- Ran the linker to build the final executable.

## Outcome
The preprocessor does not intelligently import libraries; it executes a raw text copy-paste of header files. This explains why `#include <stdio.h>` inflates a 5-line program into massive intermediate code. Furthermore, viewing the assembly output demonstrated exactly how high-level C maps to hardware instructions.

## Code Snippet
```c
#include <stdio.h>

int main() {
    printf("Hello, Embedded World\n");
    return 0;
}
```
