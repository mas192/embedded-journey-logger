## Goal
Transition away from dynamic types and understand precise memory allocation using fixed-width integers.

## Work
- Imported `<stdint.h>`.
- Explored `int8_t`, `uint8_t`, and `uint32_t`.
- Wrote a program to test the `sizeof()` operator on various types.
- Intentionally triggered an integer overflow by assigning 260 to a `uint8_t` variable.

## Outcome
Unlike dynamic languages where numbers scale automatically, memory is strictly bounded in C. Assigning 260 to an 8-bit unsigned integer (max value 255) caused it to wrap around to 4. This is a critical concept for processing raw sensor data streams, where combining multiple 8-bit registers into a 16-bit or 32-bit value requires strict memory discipline.

## Code Snippet
```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint8_t sensor_val = 260; // Intentional overflow
    printf("Value: %u\n", sensor_val); // Prints 4
    printf("Size: %zu bytes\n", sizeof(sensor_val));
    return 0;
}
```
